# GMVA image-generation prompt

This file records the prompt used to generate the final professional three-page GMVA graphic set used by the GitHub Pages site.

## Final prompt

> A clean, modern triptych infographic presents the Generic Model of Value Addition (GMVA) across three numbered panels, combining navy and gray accents, structured diagrams, calm landscape and architectural imagery, concise text blocks, and consistent footer branding. Panel 01 introduces GMVA as a universal framework for clarifying value creation; Panel 02 explains its separate function and product-build hierarchies, core economic flow, controller inputs, and guiding axioms; Panel 03 highlights applications in analysis, planning, development, research, education, and a hosting-business example.

The generated triptych was then split into three separate page images:

- `docs/01-gmva-overview-professional.png`
- `docs/02-gmva-model-professional.png`
- `docs/03-gmva-applications-professional.png`
